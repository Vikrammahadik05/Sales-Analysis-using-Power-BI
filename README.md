# Sales-Analysis-using-Power-BI

📌 Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance, profit, quantity, orders, regional performance, and customer segments.
The dashboard provides a clear overview of business performance through interactive charts, filters, and visualizations, helping users explore sales data and gain meaningful insights.

🎯 Project Objectives

  Analyze sales performance across different regions.

  Identify the top 15 states based on profit.

  Analyze profit across different payment modes.

  Understand customer segment performance.

  Analyze quantity sold across regions.
  Visualize monthly sales trends.

📊 Dashboard Features

1. Top 15 States Wise Profit

   Displays the top 15 states based on profit.

   Helps identify the most profitable states.

2. Region Filter

   Includes Central, South, East, and West regions.

   Allows users to interactively filter dashboard data.

3. Total Orders

   Displays the total number of orders.

   Provides an overview of order performance.

4. Quantity by Region

   Visualizes the quantity of products sold across different regions.

   Helps compare regional performance.

5. Profit by Payment Mode and Segment

   Analyzes profit based on payment modes.

   Compares Consumer, Corporate, and Home Office segments.

6. Monthly Sales by Region

   Displays monthly sales trends across different regions.

   Helps understand sales fluctuations over time.
